Card — white content surface with a 1px hairline border and xl radius. The base building block for feature grids, testimonials, and pricing.

```jsx
<Card hoverable padding={24}>
  <h3>Instant voice cloning</h3>
  <p>Create a digital replica of any voice.</p>
</Card>
```

Props: `hoverable` (adds the single soft-drop shadow + 2px lift), `padding` (default 24), `radius` (`lg`/`xl`/`xxl`). No heavy shadows — elevation is hairline + one soft tier only.
