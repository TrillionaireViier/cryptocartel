Button — the ElevenLabs CTA. Use `primary` (ink pill) for the single main action on a surface; `outline` for secondary; `tertiary` for inline links.

```jsx
<Button variant="primary">Try free</Button>
<Button variant="outline">Sign in</Button>
<Button variant="tertiary">Learn more</Button>
```

Variants: `primary` (warm near-black pill, hovers to `--color-primary-active`), `outline` (transparent, hairline border), `tertiary` (inline ink text), `onDark` (white pill for dark bands). Sizes: `sm` 32px · `md` 40px · `lg` 48px. Press shrinks to 0.97. Never use more than one primary per surface.
