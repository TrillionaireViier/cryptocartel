Badge — uppercase pill label for section eyebrows, status tags, and plan chips. Uses caption-uppercase type on a surface-strong plate.

```jsx
<Badge>New</Badge>
<Badge tone="dark">Pro</Badge>
<Badge tone="success">Live</Badge>
```

Tones: `neutral` (default plate), `dark`, `success`, `error`, `outline`. Keep the text short — one or two words.
